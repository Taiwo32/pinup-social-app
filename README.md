MERN Social Media Application
PingUp is a **full-stack social media web application** built using the MERN stack.  
It allows users to connect, share posts, create stories, and communicate in real-time.  
The app is designed with **scalable backend architecture**, **clean frontend design**, and **real-world social features**.

Live Demo:
https://pingup-social-app.vercel.app

🚀 Key Features
User authentication
Profile management
Post creation and likes
Stories feature
User discovery and connection requests
Real-time messaging
Media upload handling
